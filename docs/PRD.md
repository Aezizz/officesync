# Product Requirement Document (PRD) - OfficeSync

## 1. Ikhtisar Produk
OfficeSync adalah sistem kolaborasi internal modern untuk perusahaan dengan struktur multi-divisi (misal: IT Support, Marketing, Operasional).

## 2. Fitur Utama
- **Multi-Divisi & RBAC**: Admin, Manager, Staff dengan akses peran berjenjang.
- **Manajemen Tiket**: Kanban board real-time, detail tiket, komentar, dan perpindahan status tiket instan.
- **Dataset & Berkas**: Penyimpanan terstruktur dokumen dan dataset per divisi.
- **Kalender Aktivitas**: Penjadwalan rapat, deadline sprint, dan rilis.
- **Audit Log**: Pencatatan riwayat setiap aksi user untuk kepatuhan dan pelacakan.
- **Realtime Collaboration**: Sinkronisasi instan via Socket.io.
